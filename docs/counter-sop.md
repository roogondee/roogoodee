# คู่มือเคาน์เตอร์ — รหัสอ้างอิงจากเว็บ (MC- / CL-)

พิมพ์แจกเจ้าหน้าที่เคาน์เตอร์และคนรับโทรศัพท์ได้ รายละเอียดฝั่งโฆษณาอยู่ใน
`docs/clinic-google-ads.md` และ `docs/medcert-ads.md`

## รหัสนี้คืออะไร

คนที่เข้าหน้าเว็บ roogondee.com/medical-certificate หรือ /clinic จะเห็นรหัสใต้ปุ่ม เช่น
**MC-K7Q2M** (ใบรับรองแพทย์) หรือ **CL-K7Q2M** (พบแพทย์ใกล้ฉัน)

เราบันทึกรหัสนี้เพียงเพื่อรู้ว่า **โฆษณาตัวไหนพาคนมาถึงโรงพยาบาลจริง** ไม่ได้ใช้ตรวจสิทธิ์
ไม่เกี่ยวกับราคา และไม่มีผลต่อการรักษาหรือการออกใบรับรอง

- รหัสมี 2 ตัวอักษรนำหน้า ขีด และตัวอักษร/ตัวเลข 5 ตัว (ไม่มี 0, O, 1, I, L กันอ่านผิด)
- พิมพ์ตัวเล็กหรือตัวใหญ่ ใส่หรือไม่ใส่ขีดก็ได้ (`mck7q2m` ใช้ได้)
- **ผู้ป่วยที่ไม่มีรหัสให้บริการตามปกติ ห้ามบังคับขอรหัส** ห้ามถามเป็นเงื่อนไขก่อนให้บริการ

## เจอรหัสได้ 3 ทาง

| ทางไหน | ทำอย่างไร |
|---|---|
| **ทัก LINE** | ไม่ต้องทำอะไร ปุ่ม LINE ใส่รหัสในข้อความแรกให้อัตโนมัติ ระบบสร้าง lead ให้เอง และแจ้งกลุ่มเซลล์ |
| **โทรมา** | ถามว่า **"เห็นรหัสอ้างอิงบนหน้าเว็บไหมคะ"** ถ้ามี จดรหัสไว้กับนัด ถ้าไม่มีหรือไม่ทัน ข้ามได้ |
| **มาถึงโรงพยาบาล** | ถามว่า **"มีรหัสอ้างอิงจากหน้าเว็บไหมคะ"** ถ้ามี บันทึกตามหัวข้อด้านล่าง |

## บันทึกว่ามาถึงแล้ว — ทำที่ใดที่หนึ่งก็พอ

ระบบนับครั้งเดียวต่อรหัส บันทึกซ้ำไม่ทำให้นับซ้ำ

### ทาง ก. กำลังออกใบรับรองแพทย์ใน cert.roogondee.com

1. ในฟอร์มเพิ่ม/แก้ใบรับรอง ไปที่ส่วน **"ประเภทแบบฟอร์ม"**
2. กรอกช่อง **"รหัสอ้างอิงจากเว็บ (ถ้ามี)"** เช่น `MC-K7Q2M`
3. บันทึกใบรับรองตามปกติ

- รหัสไม่ถูกพิมพ์บนใบรับรอง และไม่ทำให้ผนึกของใบหลุด จึงใส่หรือแก้ทีหลังได้โดยไม่ต้องรับรองใหม่
- ระบบดึงรหัสไปนับทุกวันเวลา 10:00 น. (ย้อนหลัง 3 วัน) ผลจึงขึ้นในวันถัดไป ไม่ต้องรอ

### ทาง ข. ไม่ได้ออกใบรับรอง (ตรวจโรคทั่วไป สอบถาม ฯลฯ)

1. เปิด **roogondee.com/admin/redeem** แล้วล็อกอิน (หน้าเดียวกับที่รับ voucher)
2. พิมพ์รหัสลงช่องเดียวกับรหัส voucher แล้วกดค้นหา
3. เห็นการ์ดรหัส ให้กด **"บันทึกว่าผู้รับบริการมาแล้ว"**

ผลที่เห็นบนหน้าจอ:

| ข้อความ | ความหมาย |
|---|---|
| ✓ บันทึกแล้ว | สำเร็จ นับเป็นผู้มาตรวจแล้ว |
| ⚠ บันทึกไปแล้ว | รหัสนี้มีคนบันทึกไว้ก่อนแล้ว (เช่น ผ่านใบรับรอง) ไม่ต้องทำอะไรอีก |
| ไม่พบรหัส | พิมพ์ผิด ลองอ่านรหัสกับผู้ป่วยอีกครั้ง ถ้ายังไม่พบ ข้ามได้ ห้ามให้ผู้ป่วยรอ |

### ทาง ค. ผู้ป่วยทัก LINE มาก่อน แล้วมาตามนัด

ย้ายสถานะ lead เป็น **"มาตรวจแล้ว"** ในหน้า CRM ตามปกติ ระบบนับให้เอง ไม่ต้องใส่รหัสซ้ำ

## ห้ามทำ

- ห้ามบังคับขอรหัส หรือบอกผู้ป่วยว่ารหัสเกี่ยวกับราคา ส่วนลด หรือสิทธิ์
- ห้ามบันทึกรหัสของคนที่ยังไม่ได้มาจริง (บันทึกตอนมาถึงเท่านั้น ไม่ใช่ตอนนัด)
- ห้ามเขียนรหัสลงในเนื้อหาใบรับรอง หรือบอกรหัสให้บุคคลอื่นที่ไม่ใช่ผู้ป่วยเจ้าของรหัส
- ห้ามเอารหัสใบรับรอง (HN) ไปใส่ช่องนี้ ช่องนี้รับเฉพาะรหัส MC- / CL-

## ปัญหาที่พบบ่อย

| อาการ | ทำอย่างไร |
|---|---|
| ผู้ป่วยอ่านรหัสไม่ออก / ลืมแล้ว | ไม่เป็นไร ให้บริการต่อ ไม่ต้องบันทึก |
| ผู้ป่วยบอกว่าไม่ได้เห็นรหัสบนหน้าเว็บ | ปกติ รหัสโผล่หลังหน้าเว็บโหลดเสร็จเล็กน้อย บางเครื่องไม่แสดงถ้าเน็ตช้า ข้ามได้ |
| ใส่รหัสในใบรับรองไปแล้วแต่เช้าวันถัดไปยังไม่เห็นผล | แจ้งผู้ดูแลระบบ อาจต้องตรวจว่ารหัสพิมพ์ถูกและระบบเชื่อมต่อปกติหรือไม่ |
| ผู้ป่วยหลายคนใช้รหัสเดียวกัน | ระบบนับเพียงคนแรก ที่เหลือข้ามได้ |
